# Black Blade Barbershop

Build a complete, premium, modern barbershop website called BLACK BLADE.

Design requirements:

- Dark luxury theme using black, charcoal, white and gold.

- Modern typography and premium visual style.

- Smooth animations, scroll reveals, hover effects and page transitions.

- Fully responsive for mobile, tablet and desktop.

- Use high-quality barbershop photography.

- Create a professional navigation bar.

Website sections:

1. Hero section with a powerful headline, background image and booking button.

2. About the barbershop.

3. Services with names, descriptions and prices.

4. Gallery with haircut photos.

5. Team section with barber profiles.

6. Customer reviews using clearly labeled demo content.

7. Appointment booking section.

8. Contact information, WhatsApp button and map placeholder.

9. Professional footer.

Functional requirements:

- Booking form with customer name, phone number, service, barber, date and time.

- Form validation and clear success/error messages.

- Admin dashboard for managing appointments and services.

- Prevent double booking for the same barber and time.

- Ability to cancel or update appointments.

- Arabic and English language support with RTL layout for Arabic.

- Use realistic demo content and clearly mark placeholder business information.

Build a polished, production-oriented website. Do not create fake payment integrations. Make every button and navigation link functional. Prioritize excellent UI/UX and mobile responsiveness.
